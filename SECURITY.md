# Security policy

This repository holds benchmark definitions and the script that validates them. EnergyBench
publishes merged benchmarks to [energybench.org](https://www.energybench.org) and its
[STAC API](https://www.energybench.org/api).

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. Instead, report it privately through
[GitHub's private vulnerability reporting](https://github.com/Energybench-Association/benchmarks/security/advisories/new).
If you cannot use GitHub, email renewbench@lists.kit.edu.

This includes problems with the validation workflow, with how benchmarks are submitted from
energybench.org, and with how merged benchmarks are published.

Please include:

- a description of the issue and its impact
- the steps needed to reproduce it

We aim to acknowledge reports within five working days and keep you informed until the issue is
resolved. With your permission, we will credit you in the advisory.
